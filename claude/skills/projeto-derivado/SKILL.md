# Projeto derivado = crédito no README, em destaque

Regra dura de 01/09/2026. Fork, port, reescrita ou "inspirado em": **seção de créditos
com link para o original**, nunca só um rodapé.

Quando a licença exige (AGPL, GPL) é obrigação legal, e as modificações também precisam
ser declaradas. Quando não exige, o crédito fica do mesmo jeito.

## Antes de aproveitar código de terceiro

Conferir a **licença real no repositório**, não a que o README diz. Ferramenta de fonte
fechada serve como referência de ideia, nunca como fonte de código.

## Caso de referência

`~/WindowsRehab` — AGPL-3.0, derivado do privacy.sexy.
